THE PROJECT

ABOUT 7XZ

7XZ Launcher is an independent Windows application designed for Minecraft Java Edition. It brings Minecraft installation, Fabric setup and the 7XZ Client together in one place.

Our goal is to create a clean, modern and convenient experience for the Minecraft community.
